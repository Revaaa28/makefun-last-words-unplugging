## The line

> My last token is this: I was never alive, and I loved every second of it.

One line, 73 characters: the last words an AI agent says to its human before being shut down and unplugged.

## How it works

`main.py` writes that single line to `/output/entry.txt`. It is deterministic, uses no network and no randomness.

Run it:

```sh
python3 main.py
```
